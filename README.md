City Scope Medical Centre Website

A modern, responsive healthcare website designed for City Scope Medical Centre, Nakuru. The website provides patients and visitors with information about the medical centre, its services, departments, appointments, frequently asked questions, reviews, and contact details.

🌐 Project Overview

The City Scope Medical Centre website is designed to provide a simple and accessible online presence for the medical centre. It allows visitors to learn about available healthcare services, find important contact information, view the location, and submit an appointment request.

The website is designed with a clean healthcare-focused interface using a professional colour palette and responsive layouts for desktop and mobile devices.

✨ Features

* 🏥 Medical centre introduction and information
* 📋 Detailed healthcare services section
* 🩺 Departments information
* 📅 Appointment booking form
* ❓ Frequently Asked Questions (FAQ)
* 📞 Click-to-call contact option
* 📧 Email contact option
* 📍 Medical centre location with Google Maps
